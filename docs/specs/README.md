# 规格（Spec）总览

本目录保存 Oidrune 的 topic-level specification。每个 spec 是长期能力与
约束的契约，不是一次性任务进度卡片。

每个 topic 目录包含：

- `SPEC.md`：当前有效规范
- `IMPLEMENTATION.md`：实现覆盖和 rollout 状态
- `HISTORY.md`：主题局部生命周期与兼容性背景
